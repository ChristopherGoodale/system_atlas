# Financial Data Warehouse: how it's built

**Open it:** https://christophergoodale.github.io/system_atlas/

An interactive explanation of the financial data warehouse and the systems around it: the trading lab that uses it, and the monitoring and alerting that watch both. It opens on a **3D view**, with each layer as one floor of a building and data moving between floors on a simulated clock.

**Start with "Walk me through"** in the header. It's a 14-step guided tour of the whole system, end to end:
- overnight, prices arrive and become checked data
- at the open, the trading lab runs on it
- something breaks, and the lab and a person fix it

It plays by itself. Press Next or an arrow key to take over, and Space to resume.

The other views:

- **Map:** every service, job, schema and link, flat.
- **Tables:** the warehouse schemas, with table lineage and quality checks.
- **Tours:** five shorter guided stories, such as the nightly load, a trade, an incident from alert to phone, and an AI assistant querying the warehouse.
- **Filters:** show one flow, one link type or a few systems at a time.

The page is generated by **System Atlas**, a tool that reads the systems' own repositories (SQL migrations, transform SQL, Docker Compose, Prometheus config, schedulers) and draws the picture from them. Before anything is published, it strips hostnames, private addresses and credentials.

## Source code

This repository holds **only the built site**: minified JavaScript, CSS and a redacted `snapshot.json`. The warehouse, System Atlas and their tests are in private repositories. **They're available on request for review.**
