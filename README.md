# Financial Data Warehouse: how it's built

**Open it:** https://christophergoodale.github.io/system_atlas/

An interactive explanation of the financial data warehouse and the systems around it: the trading lab that uses it, and the monitoring and alerting that watch both. It opens on a **3D view**, with each layer as one floor of a building and data moving between floors on a simulated clock. The other views:

- **Map:** every service, job, schema and link, flat.
- **Tables:** the warehouse schemas, with table lineage and quality checks.
- **Tours:** five guided stories, such as the nightly load, a trade, an incident from alert to phone, and an AI assistant querying the warehouse.
- **Filters:** show one flow, one link type or a few systems at a time.

The page is generated by **System Atlas**, a tool that reads the systems' own repositories (SQL migrations, transform SQL, Docker Compose, Prometheus config, schedulers) and draws the picture from them. Before anything is published, it strips hostnames, private addresses and credentials.

## Source code

This repository holds **only the built site**: minified JavaScript, CSS and a redacted `snapshot.json`. The warehouse, System Atlas and their tests are in private repositories. **They're available on request for review.**

Keys: `1`–`5` start a tour · `←`/`→` step · `Space` play/pause · `E` story/engineer · `D` 3D · `M` map · `T` tables · `F` full screen
